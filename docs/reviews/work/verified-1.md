- **F03-01**: CONFIRMED — `IndexManager::rebuild_now` (`src-tauri/src/indexer/mod.rs:46-94`) has no mutex/single-flight guard against concurrent rebuilds racing on `snapshot.store` and `index.bin`. Proposed fix is correct.
- **F03-02**: CONFIRMED — `typo_fuzzy_score` (`src-tauri/src/search/ranking.rs:109-112`) omits the `abs_diff(q_len) <= max_edits` guard before `damerau_levenshtein(q, title)`. Proposed fix is correct.
- **F04-01**: CONFIRMED — `math.rs:187-242` has unbounded recursion in `parse_power`, `parse_unary`, and `parse_primary`. Proposed `MAX_RECURSION_DEPTH` guard is correct.

- **F04-04**: DOWNGRADED(MINOR) — TOCTOU in `build_output_path` (`src-tauri/src/converter/mod.rs:103-125`) is real, but impact is low in a single-user local desktop UI. Fix note: ensure any reserved placeholder file is removed on error and compatible with `pdftoppm -singlefile`.
